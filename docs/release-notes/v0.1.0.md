**The first release of oncemore: an alpha.** It makes DVD-Video and Blu-ray discs with real menus, from an authoring app on your own Mac (or in a browser on Linux), and writes the disc image itself.

> **Alpha.** Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## What it does

- **Discs:** DVD-Video (VIDEO_TS folder or ISO) and Blu-ray (BDMV folder or UDF 2.50 image); the disc image is written by oncemore itself; optional burning.
- **Menus:** still and motion menus, text and picture buttons, thumbnails (moving ones too), chapter menus made for you, colour sets, fade-in, loops and timeouts, pop-up menus on Blu-ray, layered Photoshop files as menus, guides, rotate and flip, button numbers for the number keys.
- **Titles:** chapters (from the file's markers, at intervals, or by hand), titles made of several clips and pictures, slideshows with music and transitions, music titles, several audio tracks (5.1 AC-3, AC-3 kept as it is), subtitles (SubRip, WebVTT, ASS / SSA, text scripts), 16:9 and 4:3 on one disc, interlaced, soft pulldown and inverse telecine, DVD video used without re-encoding.
- **Navigation:** end actions and overrides, playlists, play all, resume, return to the last menu, links that pick audio and subtitles, link transitions, remote keys turned off per title or menu.
- **Checking:** flowchart, project check (unreachable items, dead ends), and a remote-control simulator before anything is encoded.
- **For AI assistants:** `oncemore mcp`, an MCP server through which an assistant can author and build a disc.

## Install

**Mac app:** download `Oncemore-0.1.0-arm64.zip` (Apple silicon) or `Oncemore-0.1.0-x86_64.zip` (Intel) below. It needs `ffmpeg-full` and `dvdauthor` from Homebrew: `brew install ffmpeg-full dvdauthor`. If macOS says the app cannot be checked, Control-click it and choose **Open** (or System Settings > Privacy & Security > **Open Anyway**).

**Command line / browser app:** `pip install git+https://github.com/kajisho5/oncemore@v0.1.0`, then `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

No copy protection or region codes, ever. GPL-3.0.

## できること

- **ディスク：** DVD-Video（VIDEO_TS フォルダーまたは ISO）と Blu-ray（BDMV フォルダーまたは UDF 2.50 イメージ）。ディスクイメージは oncemore 自身が書き出します。書き込みも可能。
- **メニュー：** 静止画・動画メニュー、文字・画像ボタン、サムネイル（動くものも）、チャプターメニューの自動作成、カラーセット、フェードイン、ループとタイムアウト、Blu-ray のポップアップメニュー、レイヤー付き Photoshop ファイルの取り込み、ガイド、回転・反転、数字キー用のボタン番号。
- **タイトル：** チャプター（ファイルのマーカー・一定間隔・手動）、複数のクリップや静止画をつないだタイトル、音楽とトランジション付きのスライドショー、音楽だけのタイトル、複数の音声トラック（5.1ch AC-3、AC-3 の無変換収録）、字幕（SubRip・WebVTT・ASS / SSA・テキストスクリプト）、16:9 と 4:3 の混在、インターレース・ソフトプルダウン・逆テレシネ、DVD 規格の映像の無変換収録。
- **ナビゲーション：** 終了時の動作と上書き、プレイリスト、すべて再生、レジューム、最後のメニューへ戻る、音声・字幕を切り替えるリンク、リンクのトランジション、タイトル・メニューごとのリモコン操作の禁止。
- **確認：** フローチャート、プロジェクトのチェック（どこからも行けない項目・行き止まり）、エンコード前のリモコンシミュレータ。
- **AI アシスタント向け：** `oncemore mcp`（AI アシスタントからディスクを作れる MCP サーバー）。

## インストール

**Mac アプリ：** 下の `Oncemore-0.1.0-arm64.zip`（Apple シリコン）または `Oncemore-0.1.0-x86_64.zip`（Intel）をダウンロードしてください。Homebrew の `ffmpeg-full` と `dvdauthor` が必要です：`brew install ffmpeg-full dvdauthor`。「開発元を確認できない」と表示されたら、Control キーを押しながらクリックして **開く** を選んでください（またはシステム設定 > プライバシーとセキュリティ > **このまま開く**）。
