**oncemore 0.4.0: still an alpha.** What is new since 0.3.0:

> **Alpha.** Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## New

- **No more dvdauthor or spumux.** oncemore writes the DVD's VIDEO_TS itself, with [vtskit](https://github.com/kajisho5/vtskit) (bundled; LGPL-3.0-or-later): the IFO files, the navigation packs, the menus with their buttons, and the subtitles. vtskit's tests give the same titles and menus to dvdauthor and to vtskit and check that the files come out byte for byte the same; oncemore's own tests play its discs back with libdvdnav as before. ffmpeg is the only tool to install now.
- **Multi-angle titles** (DVD): a title can have up to 9 views of the same scene, which the viewer switches with the remote's Angle key. They are set in the project file (`angles`; also through the MCP server); the app's editor does not show them yet. A Blu-ray build leaves them out with a warning. Angle discs are checked with libdvdnav; dvdauthor could not make them, so there is nothing to compare them with, and a set-top player check is still owed.

## Install

**Mac app:** download `Oncemore-0.4.0-arm64.zip` (Apple silicon) or `Oncemore-0.4.0-x86_64.zip` (Intel) below. It needs `ffmpeg-full` from Homebrew: `brew install ffmpeg-full` (dvdauthor is no longer needed). If macOS says the app cannot be checked, Control-click it and choose **Open** (or System Settings > Privacy & Security > **Open Anyway**).

**Command line / browser app:** `pip install git+https://github.com/kajisho5/oncemore@v0.4.0`, then `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

Projects made with earlier versions open as they are.

No copy protection or region codes, ever. GPL-3.0.

**oncemore 0.4.0（アルファ版）です。** 0.3.0 からの新機能：

> **アルファ版です。** すべての機能は変更のたびに自動テストし、作ったディスクを libdvdnav・libbluray（VLC が使うライブラリ）で再生して確かめていますが、**家庭用プレーヤーの実機ではまだ確認していません。** oncemore で作ったディスクを実機で再生したら、機種名と結果を [Issue](https://github.com/kajisho5/oncemore/issues) で教えてください。

## 新機能

- **dvdauthor・spumux が不要になりました。** DVD の VIDEO_TS（IFO ファイル、ナビゲーションパック、ボタン付きのメニュー、字幕）を、同梱の [vtskit](https://github.com/kajisho5/vtskit)（LGPL-3.0 以降）で oncemore 自身が書き出します。vtskit のテストでは同じタイトルとメニューを dvdauthor と vtskit に渡し、ファイルがバイト単位で一致することを確かめています。oncemore のテストでは、これまでどおり作ったディスクを libdvdnav で再生して確かめています。インストールが必要なのは ffmpeg だけです。
- **マルチアングル**（DVD）：1 つのタイトルに同じ場面の映像を 9 つまで入れ、リモコンのアングルキーで切り替えられます。設定はプロジェクトファイル（`angles`。MCP サーバー経由でも可）で行います。アプリの編集画面にはまだ表示されません。Blu-ray のビルドでは警告を出して省きます。アングルのディスクは libdvdnav で確かめています（dvdauthor では作れなかったため比べる相手がなく、実機での確認はまだです）。

## インストール

**Mac アプリ：** 下の `Oncemore-0.4.0-arm64.zip`（Apple シリコン）または `Oncemore-0.4.0-x86_64.zip`（Intel）をダウンロードしてください。Homebrew の `ffmpeg-full` が必要です：`brew install ffmpeg-full`（dvdauthor はもう不要です）。「開発元を確認できない」と表示されたら、Control キーを押しながらクリックして **開く** を選んでください（またはシステム設定 > プライバシーとセキュリティ > **このまま開く**）。

**コマンドライン／ブラウザ版：** `pip install git+https://github.com/kajisho5/oncemore@v0.4.0` のあと `oncemore doctor`、`oncemore gui`。詳しくは [README](https://github.com/kajisho5/oncemore/blob/main/README.ja.md) を。

これまでの版で作ったプロジェクトはそのまま開けます。
