**oncemore 1.2.1.** Fixes since 1.2.0, from a review of the whole project:

> Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## Fixed

- A title that is only sound (a still or black picture) with closed captions or film pulldown lost its picture and its captions on the disc.
- The disc plan counts everything before anything is encoded: a picture used as it is at its own bitrate, the files put beside the video (`disc.rom_files`), motion menus and link transitions, and a Blu-ray's menus. A project that cannot fit now says so at the start instead of after encoding.
- The web version is no longer held to a BD25's size.
- 720p Blu-rays at 50 / 59.94 from interlaced sources keep the motion of each field.
- With a media cache folder chosen (Preferences), titles made of clips and slideshows play in the app again.
- Clearer messages instead of errors for unusual input: simulator keys, a chapter menu's label format, AI assistant (MCP) tools, a subtitle cue with no time, a player state for a title since deleted.
- The app keeps the right title and project after switching, Save As and renaming, and says when a template, a new project or a subtitle cannot be made.
- Wording: seven labels showed the wrong text (for example "+ Add a picture…" on a menu's toolbar); the Japanese uses one word for each thing; the window's tooltips are translated.
- The Mac app waits for its engine reliably when a project folder has a non-English name.
- The README and the manual describe buttons over a title, subtitle formats and the install as they are.

## Install

**Mac app:** download `Oncemore-1.2.1-arm64.zip` (Apple silicon) or `Oncemore-1.2.1-x86_64.zip` (Intel) below, unzip it and move *Oncemore.app* to Applications. It is signed and notarised, and needs nothing else installed.

**Command line / browser app:** `brew install ffmpeg-full` (on a Mac), then `pip install git+https://github.com/kajisho5/oncemore@v1.2.1`, `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

The source of the app's ffmpeg (GPL) is attached below. No copy protection or region codes, ever. GPL-3.0.

## 修正

- 音声だけのタイトル（静止画か黒の映像）にクローズドキャプションやフィルムのプルダウンを付けると、ディスクから映像とキャプションが消えていました。
- 容量の計画を、エンコードの前にすべて数えるようにしました。そのまま使う映像のビットレート、映像と並べて入れるファイル（`disc.rom_files`）、モーションメニューとリンクトランジション、Blu-ray のメニューです。入りきらないプロジェクトは、エンコードの後ではなく最初に知らせます。
- Web 版が BD25 の容量で制限されなくなりました。
- インターレース素材から作る 50／59.94 の 720p Blu-ray で、フィールドごとの動きを保ちます。
- メディアキャッシュのフォルダーを指定したとき（環境設定）、クリップでできたタイトルとスライドショーがアプリで再生できなかったのを直しました。
- 想定外の入力でエラーになっていた箇所で、わかりやすいメッセージを出すようにしました（シミュレーターのキー、チャプターメニューの見出しの書式、AI アシスタント（MCP）のツール、時刻のない字幕、削除したタイトルを指すプレビューの状態）。
- プロジェクトの切り替え・別名で保存・名前の変更のあとも、正しいタイトルとプロジェクトを保ちます。テンプレート、新規プロジェクト、字幕が作れなかったときは、その旨を表示します。
- 表示の文言：7 か所で違う文言が出ていました（たとえばメニューのツールバーに「＋写真を追加…」）。日本語の用語を統一し、ウィンドウのツールチップも翻訳しました。
- プロジェクトのフォルダー名が日本語などのとき、Mac アプリがエンジンの起動を確実に待つようにしました。
- README と説明書の、タイトル上のボタン・字幕の形式・インストールの記述を実際に合わせました。
