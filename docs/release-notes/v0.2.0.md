**oncemore 0.2.0: still an alpha.** What is new since 0.1.0:

> **Alpha.** Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## New

- **Web version:** `build --format web` (File > Build > Web (HTML5)) makes a folder a browser plays as the disc: the menus with their buttons and remote keys, the titles as MP4 with chapters and subtitles.
- **Closed captions** on NTSC DVDs (line 21), from a Scenarist (.scc) file or from subtitles.
- **Dual-layer DVDs:** choose the chapter where the disc goes on to its second layer (Disc > Layer break), or let oncemore pick one; the image puts it on an ECC block and burning passes it to the writer.
- **Paragraphs:** menu texts of several lines, lined up left, centred or right, with line spacing.
- **My styles:** save the look of a text, button or shape (font, size, colour, outline, shadow) and use it in any project.
- **Image scripts:** subtitles that are pictures, each shown in its own colours.
- **DTS** sound kept as it is from the sources, on DVD and Blu-ray.
- **Blu-ray:** H.264 video that already meets the Blu-ray rules is used without re-encoding.
- **Check for Updates** (Help menu): shows which version you have and opens the releases page. oncemore itself never connects to the internet.
- **Support oncemore:** a Sponsor link in the Help menu and the About box.

## Install

**Mac app:** download `Oncemore-0.2.0-arm64.zip` (Apple silicon) or `Oncemore-0.2.0-x86_64.zip` (Intel) below. It needs `ffmpeg-full` and `dvdauthor` from Homebrew: `brew install ffmpeg-full dvdauthor`. If macOS says the app cannot be checked, Control-click it and choose **Open** (or System Settings > Privacy & Security > **Open Anyway**).

**Command line / browser app:** `pip install git+https://github.com/kajisho5/oncemore@v0.2.0`, then `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

Projects made with 0.1.0 open as they are.

No copy protection or region codes, ever. GPL-3.0.

> **アルファ版です。** すべての機能は変更のたびに自動テストし、作ったディスクを libdvdnav・libbluray（VLC が使うライブラリ）で再生して確かめていますが、**家庭用プレーヤーの実機ではまだ確認していません。** oncemore で作ったディスクを実機で再生したら、機種名と結果を [Issue](https://github.com/kajisho5/oncemore/issues) で教えてください。

## 新機能

- **Web 版：** `build --format web`（ファイル > ビルド > Web（HTML5））で、ブラウザでディスクのように再生できるフォルダーを書き出します。メニューのボタンとリモコンキー、チャプターと字幕付きの MP4 のタイトルが入ります。
- **字幕放送用キャプション**（クローズドキャプション、NTSC の DVD、ライン 21）：Scenarist（.scc）ファイル、または字幕ファイルから。
- **2 層 DVD：** 2 層目へ移るチャプターを選べます（ディスク > レイヤーブレーク。自動でも可）。イメージは ECC ブロック境界に合わせて書き出し、書き込み時にドライブへ位置を渡します。
- **段落：** メニューの複数行のテキストを、左揃え・中央揃え・右揃えと行間を指定して置けます。
- **マイスタイル：** テキスト・ボタン・図形の見た目（フォント・サイズ・色・縁取り・影）を保存して、どのプロジェクトでも使えます。
- **画像の字幕スクリプト：** 画像の字幕を、それぞれの色のまま表示します。
- **DTS 音声**を DVD・Blu-ray とも無変換で収録。
- **Blu-ray：** すでに Blu-ray の規格に合う H.264 映像は再エンコードせずに使います。
- **アップデートを確認**（ヘルプメニュー）：今の版を表示し、リリースのページを開きます。oncemore 自身はインターネットに接続しません。
- **oncemore を支援する：** ヘルプメニューと「このアプリについて」にスポンサーへのリンク。

## インストール

**Mac アプリ：** 下の `Oncemore-0.2.0-arm64.zip`（Apple シリコン）または `Oncemore-0.2.0-x86_64.zip`（Intel）をダウンロードしてください。Homebrew の `ffmpeg-full` と `dvdauthor` が必要です：`brew install ffmpeg-full dvdauthor`。「開発元を確認できない」と表示されたら、Control キーを押しながらクリックして **開く** を選んでください（またはシステム設定 > プライバシーとセキュリティ > **このまま開く**）。

**コマンドライン／ブラウザ版：** `pip install git+https://github.com/kajisho5/oncemore@v0.2.0` のあと `oncemore doctor`、`oncemore gui`。詳しくは [README](https://github.com/kajisho5/oncemore/blob/main/README.ja.md) を。

0.1.0 で作ったプロジェクトはそのまま開けます。
