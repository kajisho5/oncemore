**oncemore 0.3.0: still an alpha.** What is new since 0.2.0:

> **Alpha.** Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## New

- **Menus with pages** (Menu > Add new page): a menu's buttons spread over several pages, turned with buttons to the next, previous or a given page. A heading or a background shape can be on every page. Each page is a menu of its own on the disc (DVD, Blu-ray and the web version).
- **Random and shuffled playlists** on Blu-ray and the web version (DVD keeps the order).
- **Slideshows of up to 999 pictures** on Blu-ray; on DVD the pictures after the 99th go in the last chapter.
- **Bit budget:** for each title and menu, the bitrate and the space it takes on the disc, as a bar of the whole disc, before anything is encoded.
- **Media cache in a folder you choose** (Preferences).
- **Chapters at scene changes** (Timeline > Add chapter points at scene changes, or `oncemore scenes`).
- **Bold, italic, letter spacing and kerning** for menu texts and buttons. Bold and italic use those faces of the font's family, when the family has them.
- **Button highlights:** a button can light up by its own pixels (the letters, or a picture's opaque pixels), a frame, a line under it, or a rectangle or ellipse drawn on the menu. The drawn shape is dragged and sized on the menu.

## Install

**Mac app:** download `Oncemore-0.3.0-arm64.zip` (Apple silicon) or `Oncemore-0.3.0-x86_64.zip` (Intel) below. It needs `ffmpeg-full` and `dvdauthor` from Homebrew: `brew install ffmpeg-full dvdauthor`. If macOS says the app cannot be checked, Control-click it and choose **Open** (or System Settings > Privacy & Security > **Open Anyway**).

**Command line / browser app:** `pip install git+https://github.com/kajisho5/oncemore@v0.3.0`, then `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

Projects made with 0.1.0 and 0.2.0 open as they are.

No copy protection or region codes, ever. GPL-3.0.

**oncemore 0.3.0（アルファ版）です。** 0.2.0 からの新機能：

> **アルファ版です。** すべての機能は変更のたびに自動テストし、作ったディスクを libdvdnav・libbluray（VLC が使うライブラリ）で再生して確かめていますが、**家庭用プレーヤーの実機ではまだ確認していません。** oncemore で作ったディスクを実機で再生したら、機種名と結果を [Issue](https://github.com/kajisho5/oncemore/issues) で教えてください。

## 新機能

- **ページのあるメニュー**（メニュー > 新規ページを追加）：メニューのボタンを複数のページに分け、次のページ・前のページ・指定したページへ移るボタンでめくります。見出しや背景の図形はすべてのページに置けます。ディスクではページごとに別のメニューになります（DVD・Blu-ray・Web 版）。
- **ランダム再生・シャッフル再生のプレイリスト**（Blu-ray と Web 版。DVD は順番どおり）。
- **999 枚までのスライドショー**（Blu-ray。DVD では 100 枚目以降を最後のチャプターにまとめます）。
- **ビット配分：** エンコード前に、タイトルとメニューごとのビットレートとディスク上の容量を、ディスク全体の帯グラフで表示します。
- **メディアキャッシュの保存先**を選べます（環境設定）。
- **シーンの変わり目にチャプター**（タイムライン > シーンチェンジにチャプターポイントを追加、または `oncemore scenes`）。
- **太字・斜体・文字間隔・カーニング**（メニューのテキストとボタン）。太字と斜体はフォントファミリーにその書体がある場合に使えます。
- **ボタンのハイライト：** ボタン自身の形（文字、または画像の不透明部分）・周りの枠・下線・メニュー上に描いた四角形か楕円から選べます。描いた図形はメニュー上でドラッグして動かし、大きさを変えられます。

## インストール

**Mac アプリ：** 下の `Oncemore-0.3.0-arm64.zip`（Apple シリコン）または `Oncemore-0.3.0-x86_64.zip`（Intel）をダウンロードしてください。Homebrew の `ffmpeg-full` と `dvdauthor` が必要です：`brew install ffmpeg-full dvdauthor`。「開発元を確認できない」と表示されたら、Control キーを押しながらクリックして **開く** を選んでください（またはシステム設定 > プライバシーとセキュリティ > **このまま開く**）。

**コマンドライン／ブラウザ版：** `pip install git+https://github.com/kajisho5/oncemore@v0.3.0` のあと `oncemore doctor`、`oncemore gui`。詳しくは [README](https://github.com/kajisho5/oncemore/blob/main/README.ja.md) を。

0.1.0・0.2.0 で作ったプロジェクトはそのまま開けます。
