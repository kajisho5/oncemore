**oncemore 1.2.0.** What is new since 1.1.0:

> Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## New

- **The Mac app needs nothing installed**: it now carries its own ffmpeg and ffprobe (FFmpeg 9 with x264, FreeType and HarfBuzz), so Homebrew is no longer needed. Download, unzip, open. The command line and the browser app still use the ffmpeg you install.

## Notes

- The app's ffmpeg is GPL; its source code (FFmpeg, x264, FreeType, HarfBuzz, exactly as built) is attached below, and the licences are inside the app (*Oncemore.app/Contents/Resources/ffmpeg*).
- The app is larger because of it.

## Install

**Mac app:** download `Oncemore-1.2.0-arm64.zip` (Apple silicon) or `Oncemore-1.2.0-x86_64.zip` (Intel) below, unzip it and move *Oncemore.app* to Applications. It is signed and notarised.

**Command line / browser app:** `brew install ffmpeg-full` (on a Mac), then `pip install git+https://github.com/kajisho5/oncemore@v1.2.0`, `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

No copy protection or region codes, ever. GPL-3.0.

**oncemore 1.2.0 です。** 1.1.0 からの新機能：

## 新機能

- **Mac アプリはインストールするだけで使えます**：ffmpeg と ffprobe（x264・FreeType・HarfBuzz 入りの FFmpeg 9）をアプリに同梱したので、Homebrew は要りません。ダウンロードして展開し、開くだけです。コマンドライン版とブラウザ版は、これまでどおり自分で入れた ffmpeg を使います。

## 補足

- 同梱の ffmpeg は GPL です。ビルドしたとおりのソース（FFmpeg、x264、FreeType、HarfBuzz）を下に添付し、ライセンス文はアプリの中（*Oncemore.app/Contents/Resources/ffmpeg*）に入れています。
- そのぶんアプリは大きくなりました。

**Mac アプリ：** 下の `Oncemore-1.2.0-arm64.zip`（Apple シリコン）または `Oncemore-1.2.0-x86_64.zip`（Intel）をダウンロードして展開し、*Oncemore.app* を「アプリケーション」に入れてください。署名・公証済みです。

**コマンドライン／ブラウザ版：** Mac では `brew install ffmpeg-full` のあと、`pip install git+https://github.com/kajisho5/oncemore@v1.2.0`、`oncemore doctor`、`oncemore gui`。詳しくは [README](https://github.com/kajisho5/oncemore/blob/main/README.ja.md) を。

コピーガードとリージョンコードは今後も一切入れません。GPL-3.0。
