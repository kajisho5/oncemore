**oncemore 1.0.0.** What is new since 0.5.0:

> Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## New

- **The Mac app is signed and notarised**: it opens like any app you download, with no trip to Privacy & Security.
- **Navigation scripts** (DVD): a link can run a few lines of the command language the disc's player runs, with variables (`$n += 1; if ($n >= 2) { $n = 0; play title:t2; } else play menu:main;`), such as a button that plays a title every second press, or a random choice (`random(n)`). Write them in the disc's Properties, where each is checked as you type and shows where it goes; choose one as any link, and Preview runs it and shows its variables.
- **Menu pictures adjusted**: crop, brightness, contrast and saturation for a menu's background and its pictures, shown on the stage as the disc gets them.
- **Button thumbnails cut to a shape**: rounded corners, an ellipse, or a picture's opaque part.
- **Pages from Photoshop**: a layered file's top-level "(page)" groups become pages of one menu, with Next and Previous buttons linked between them.
- **Objects coming in on a menu**: a text or picture can move in, grow (pictures) and fade in, once, from a time into the menu; such a menu becomes a motion menu on DVD, Blu-ray and the web version. Check project names the loop point that plays it once.

## Install

**Mac app:** download `Oncemore-1.0.0-arm64.zip` (Apple silicon) or `Oncemore-1.0.0-x86_64.zip` (Intel) below, unzip it and move *Oncemore.app* to Applications. It needs `ffmpeg-full` from Homebrew: `brew install ffmpeg-full`.

**Command line / browser app:** `pip install git+https://github.com/kajisho5/oncemore@v1.0.0`, then `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

Projects made with earlier versions open as they are.

No copy protection or region codes, ever. GPL-3.0.

**oncemore 1.0.0 です。** 0.5.0 からの新機能：

> すべての機能は変更のたびに自動テストし、作ったディスクを libdvdnav・libbluray（VLC が使うライブラリ）で再生して確かめていますが、**家庭用プレーヤーの実機ではまだ確認していません。** oncemore で作ったディスクを実機で再生したら、機種名と結果を [Issue](https://github.com/kajisho5/oncemore/issues) で教えてください。

## 新機能

- **Mac アプリを署名・公証しました**：ふつうのダウンロードしたアプリと同じように開けます。「プライバシーとセキュリティ」での操作は要りません。
- **ナビゲーションスクリプト**（DVD）：リンクから、プレーヤーが実行するコマンド言語の短いスクリプトを変数付きで動かせます（`$n += 1; if ($n >= 2) { $n = 0; play title:t2; } else play menu:main;`）。2 回押すごとにタイトルを再生するボタンや、ランダムな選択（`random(n)`）などに使えます。ディスクのプロパティで書き、入力中にチェックされて行き先が表示されます。どのリンクにも選べて、プレビューで実行して変数の値を確かめられます。
- **メニュー画像の調整**：メニューの背景と画像の切り抜き、明るさ、コントラスト、彩度。ステージにはディスクと同じ見た目で表示します。
- **ボタンのサムネイルの形**：角丸、楕円、画像の不透明な部分で切り抜けます。
- **Photoshop からのページ**：レイヤーファイルの最上位の「(page)」グループが 1 つのメニューのページになり、「次へ」「前へ」ボタンがページ間をつなぎます。
- **メニューに入ってくるオブジェクト**：テキストや画像が、メニューの指定の時刻から一度だけ、移動して入る・（画像は）大きくなる・フェードインします。そのメニューは DVD・Blu-ray・Web 版でモーションメニューになります。プロジェクトのチェックで、一度だけ再生されるループポイントを教えます。

## インストール

**Mac アプリ：** 下の `Oncemore-1.0.0-arm64.zip`（Apple シリコン）または `Oncemore-1.0.0-x86_64.zip`（Intel）をダウンロードして展開し、*Oncemore.app* を「アプリケーション」に入れてください。Homebrew の `ffmpeg-full` が必要です：`brew install ffmpeg-full`。

**コマンドライン／ブラウザ版：** `pip install git+https://github.com/kajisho5/oncemore@v1.0.0` のあと `oncemore doctor`、`oncemore gui`。詳しくは [README](https://github.com/kajisho5/oncemore/blob/main/README.ja.md) を。

これまでの版で作ったプロジェクトはそのまま開けます。
