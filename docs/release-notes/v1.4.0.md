**oncemore 1.4.0.** What is new since 1.3.0:

> Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. Please burn the player test disc (`oncemore testdisc`), try it on your DVD or Blu-ray player and [report the results](https://github.com/kajisho5/oncemore/issues/new?template=player-test.md).

## New

- **One disc per session, in batch.** `oncemore batch <template> sessions.csv -o <folder>` builds one DVD image for each row of a CSV, all from the same template project. For example, a meeting can give each speaker the recording of their talk. `{{column}}` in the template's texts (the disc label, a title's video or name, the menu texts) is replaced with the row's value, and the `name` column names each image. Every row is checked before anything is encoded. Each image is then read back and verified, and `manifest.json` lists the images with their size and SHA-256. `examples/batch` is a three-session template.
- **Closed-caption warnings name the subtitle.** A subtitle that line-21 captions cannot carry as written is reported with its number and time, for example `cue 3 at 00:00:06.500: ...`. That covers characters that become spaces, long lines that are wrapped, rows after the fourth that are left out, vertical text, and captions shown late. Before, the whole file got one total line. (dvdcc 0.2.0)
- **For AI assistants.** A root `SKILL.md` describes the command line and the MCP server, and `oncemore contract --json` prints what oncemore provides.

## Install

**Mac app:** download `Oncemore-1.4.0-arm64.zip` (Apple silicon) or `Oncemore-1.4.0-x86_64.zip` (Intel) below. Unzip it and move *Oncemore.app* to Applications. It is signed and notarised, and needs nothing else installed.

**Command line / browser app:** on a Mac, run `brew install ffmpeg-full` first. Then run `pip install git+https://github.com/kajisho5/oncemore@v1.4.0`, `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

The source of the app's ffmpeg (GPL) is attached below. No copy protection or region codes, ever. GPL-3.0.

## 新機能

- **セッションごとのディスクをまとめて作成**：`oncemore batch <テンプレート> sessions.csv -o <フォルダー>` は、1 つのテンプレートプロジェクトから、CSV の 1 行ごとに DVD イメージを 1 枚ずつ作ります。たとえば学会で、演者ごとに講演の記録ディスクを配るときに使えます。テンプレートのテキスト（ディスクラベル、タイトルの動画や名前、メニューの文字）にある `{{列名}}` は、各行の値に置き換わります。`name` 列は各イメージのファイル名になります。エンコードの前に全行を確認し、できたイメージは 1 枚ずつ読み戻して検証します。`manifest.json` には各イメージのサイズと SHA-256 が載ります。`examples/batch` は 3 セッション分のテンプレートです。
- **クローズドキャプションの警告に字幕の番号と時刻**：キャプションでそのまま表せない字幕を、番号と時刻つきで 1 件ずつ知らせます（例：`cue 3 at 00:00:06.500: ...`）。対象は、空白になる文字、折り返した長い行、省いた 5 行目以降、縦書き、表示の遅れです。以前はファイル全体で 1 行の合計だけでした（dvdcc 0.2.0）。
- **AI アシスタント向け**：ルートの `SKILL.md` でコマンドラインと MCP サーバーの使い方を説明しています。`oncemore contract --json` は oncemore が提供する機能を出力します。
