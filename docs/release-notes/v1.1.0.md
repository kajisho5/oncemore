**oncemore 1.1.0.** What is new since 1.0.0:

> Every feature is tested automatically on each change, and discs are played back through libdvdnav and libbluray (the libraries VLC uses), but **not yet on set-top players**. If you play a disc made with oncemore on a DVD or Blu-ray player, please [open an issue](https://github.com/kajisho5/oncemore/issues) with the player's make and model and what worked.

## New

- **DTS-HD kept whole on a Blu-ray**: DTS-HD Master Audio and High Resolution sources go onto a Blu-ray as they are (48, 96 or 192 kHz, 7.1 too), and the picture leaves room for the sound's peaks. A DVD still takes the DTS core. 7.1 DTS sources can now be used at all (a DVD gets their 5.1 core).
- **Choose DVD or Blu-ray when you make a project**: New Project has an *Authoring mode* (DVD or Blu-ray); the disc's Properties change it later. Build, Check project and the command line make that format unless told otherwise.
- **A Blu-ray project looks like one**: the disc's Properties show the BD size and picture; settings that only a DVD has (buttons over a title, angles, closed captions, navigation scripts, the per-title DVD bitrate) say so and cannot be added; Check project checks for the format you build.
- **The disc's font** can be chosen in the disc's Properties.
- **The timeline's tab** lists the titles to open.

## Fixed

- The web version no longer stops on buttons over a title: it plays the title without them.
- Check project checks the web version as it is built (`oncemore validate --format web`).
- The Build panel's notes and progress no longer speak of a DVD when making a Blu-ray ("Authoring VIDEO_TS", "Burned to the DVD"), and the format chosen there is forgotten when another project opens.
- Show highlights and Exact preview follow the page of a menu shown.
- Controls that did nothing are gone (panel menus, close boxes on tabs, one-choice lists), and wrong or outdated texts in the app, the manual and the README are corrected.

## Install

**Mac app:** download `Oncemore-1.1.0-arm64.zip` (Apple silicon) or `Oncemore-1.1.0-x86_64.zip` (Intel) below, unzip it and move *Oncemore.app* to Applications. It is signed and notarised. It needs `ffmpeg-full` from Homebrew: `brew install ffmpeg-full`.

**Command line / browser app:** `pip install git+https://github.com/kajisho5/oncemore@v1.1.0`, then `oncemore doctor` and `oncemore gui`. See the [README](https://github.com/kajisho5/oncemore#readme).

Projects made with earlier versions open as they are (made for a DVD, as before).

No copy protection or region codes, ever. GPL-3.0.

**oncemore 1.1.0 です。** 1.0.0 からの新機能：

> すべての機能は変更のたびに自動テストし、作ったディスクを libdvdnav・libbluray（VLC が使うライブラリ）で再生して確かめていますが、**家庭用プレーヤーの実機ではまだ確認していません。** oncemore で作ったディスクを実機で再生したら、機種名と結果を [Issue](https://github.com/kajisho5/oncemore/issues) で教えてください。

## 新機能

- **Blu-ray で DTS-HD を丸ごと収録**：DTS-HD Master Audio・High Resolution の素材を、そのまま（48／96／192kHz、7.1ch も）Blu-ray に入れます。音声のピークの分だけ映像のビットレートを空けます。DVD には従来どおり DTS のコア部分を入れます。7.1ch の DTS 素材も使えるようになりました（DVD には 5.1ch のコア部分）。
- **プロジェクトを作るときに DVD か Blu-ray を選択**：新規プロジェクトに「オーサリングモード」（DVD か Blu-ray）を設けました。あとからディスクのプロパティで変えられます。ビルド、プロジェクトのチェック、コマンドラインは、指定しなければこの形式を作ります。
- **Blu-ray 向けのプロジェクトらしい画面に**：ディスクのプロパティに BD の容量と映像サイズを表示します。DVD にしかない設定（タイトル上のボタン、アングル、クローズドキャプション、ナビゲーションスクリプト、タイトルごとの DVD のビットレート）はその旨を表示し、追加できなくしました。プロジェクトのチェックは、ビルドする形式で確認します。
- **ディスクのフォント**をディスクのプロパティで選べます。
- **タイムラインのタブ**からタイトルの一覧を開けます。

## 修正

- Web 版のビルドが、タイトル上のボタンで止まらなくなりました（ボタンなしでタイトルを再生します）。
- プロジェクトのチェックで、Web 版をビルドするときと同じ条件で確認できます（`oncemore validate --format web`）。
- Blu-ray を作るときに、ビルドパネルの表示や進行状況が DVD のこととして出なくなりました（「VIDEO_TS を構成」「DVD に書き込みました」）。ビルドパネルで選んだ形式は、別のプロジェクトを開くと元に戻ります。
- 「ハイライトを表示」と「正確なプレビュー」が、表示中のメニューのページに従います。
- 押しても何も起きなかったもの（パネルメニュー、タブの閉じるボタン、選択肢が 1 つだけのリスト）を外し、アプリ・説明書・README の誤った説明や古い説明を直しました。

## インストール

**Mac アプリ：** 下の `Oncemore-1.1.0-arm64.zip`（Apple シリコン）または `Oncemore-1.1.0-x86_64.zip`（Intel）をダウンロードして展開し、*Oncemore.app* を「アプリケーション」に入れてください。署名・公証済みです。Homebrew の `ffmpeg-full` が必要です：`brew install ffmpeg-full`。

**コマンドライン／ブラウザ版：** `pip install git+https://github.com/kajisho5/oncemore@v1.1.0` のあと `oncemore doctor`、`oncemore gui`。詳しくは [README](https://github.com/kajisho5/oncemore/blob/main/README.ja.md) を。

これまでの版で作ったプロジェクトはそのまま開けます（これまでどおり DVD 向けとして）。

コピーガードとリージョンコードは今後も一切入れません。GPL-3.0。
