DVD と Blu-ray を、
もう一度自分の手で。

oncemore は、手持ちの動画から本物のメニューが入ったディスクを作ります。リモコンで選ぶと光るボタン、サムネイル付きのチャプターメニュー、プレイリスト、字幕、そして再生・マウント・書き込みができるディスクイメージまで。自分の Mac でもブラウザでも動く、オープンソースのソフトです。

インストール GitHub でソースを見る

メニューからディスクイメージまで

ディスクに必要なものを、1 年後にまた開けるひとつのプロジェクトにまとめます。

ディスクらしく動くメニュー

静止画や動画の背景、選択時と決定時のハイライト色、リモコンでの移動先、既定のボタンと前回のボタン、ボタンとリンク先の間に挟む短い映像。レイヤー付きの Photoshop ファイルからもメニューを作れます。

チャプターとプレイリスト

タイムライン上のチャプター、サムネイル付きのチャプターメニュー、タイトルやチャプター範囲を並べたプレイリスト、すべて再生、そしてそれぞれが終わったあとの行き先。

音声と字幕

複数の音声トラック、5.1ch の AC-3、SRT・WebVTT・ASS からの字幕とその見た目、ストリームを切り替えるボタン。

スライドショー

写真と音楽、トランジション、パンとズーム。音楽の長さに合わせることも、リモコンで 1 枚ずつ送ることもできます。

Blu-ray も

HD のタイトル、メニューとポップアップメニュー、PGS 字幕。BDMV フォルダか UDF 2.50 のイメージに書き出します。

焼く前に確かめる

ディスク全体のフローチャート、プロジェクトのチェック、エンコード前にディスクを再生できるリモコン付きシミュレーター。

ディスクイメージも自前で

ISO（UDF と ISO 9660）は oncemore 自身が書き出します。空のディスクへの書き込みは最後の任意の一手です。

アプリでもコマンドでも

同じオーサリングアプリを Mac のウインドウでもブラウザのタブでも。その下に、JSON ファイル 1 つからディスクを作るコマンドラインがあります。

できあがる前に、ディスクを見る

エディタはディスクをそのまま見せます。プレーヤーが描くとおりのメニュー、すべてのつながり、そして試すためのリモコン。

インストール

oncemore は Python 3.11 以降の標準ライブラリだけで動きます。エンコードとオーサリングには ffmpeg と dvdauthor を使い、足りないものがあれば oncemore doctor が教えてくれます。

macOS（Homebrew）

brew install ffmpeg-full dvdauthor
pip install git+https://github.com/kajisho5/oncemore
oncemore gui my-disc

Debian / Ubuntu

sudo apt-get install ffmpeg dvdauthor genisoimage
pip install git+https://github.com/kajisho5/oncemore
oncemore gui my-disc

oncemore gui は、自分のマシンから配信するアプリをブラウザで開きます。同じアプリを Mac のウインドウで動かす Oncemore.app（Apple シリコンと Intel）は、最初のリリースから Releases ページで配布します。それまでは README に自分でビルドする方法があります。
