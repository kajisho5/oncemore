Author DVDs and Blu-ray discs once more.

oncemore turns your videos into discs with real menus: buttons that light up under the remote, chapter menus with thumbnails, playlists, subtitles, and a disc image you can play, mount or burn. It runs on your own Mac or in your browser, and it is open source.

Install Source on GitHub

From the menu to the disc image

Everything a disc needs, in one project you can open again next year.

Menus that behave like a disc's

Still or motion backgrounds, highlight and activated colours, remote-control routing, default and remembered buttons, a short video between a button and where it leads, menus from layered Photoshop files.

Chapters and playlists

Chapter points on a timeline, chapter menus with thumbnails, playlists of titles and chapter ranges, Play all, and what happens when each one ends.

Sound and subtitles

Several audio tracks, 5.1 AC-3, subtitles from SRT, WebVTT or ASS with their own look, and buttons that switch streams.

Slideshows

Pictures with music, transitions, pan and zoom, fitted to the music or advanced by hand with the remote.

Blu-ray too

HD titles, menus and pop-up menus, PGS subtitles, written as a BDMV folder or a UDF 2.50 image.

Check before you burn

A flowchart of the whole disc, a project check, and a remote-control simulator that plays the disc before anything is encoded.

The disc image, built in

oncemore writes the ISO (UDF and ISO 9660) itself. Burning it to a blank disc is an optional last step.

An app or a command

The same authoring app in a Mac window or a browser tab, on top of a command line that builds the disc from one JSON file.

See the disc before it exists

The editor shows the disc exactly: the menus as a player draws them, the links between everything, and a remote control to try it.

Yours, for good

These are the reasons oncemore exists. The tests guard each one, so they cannot quietly go away.

  • Open sourceGPL-3.0-or-later. Read it, change it, keep it.
  • No accountNo sign-in, no network access, no telemetry.
  • No copy protectionNo region codes and no copy protection, ever.
  • Plain filesA project is one JSON file next to your media.

Install

oncemore is Python 3.11 or newer with nothing but the standard library. It uses ffmpeg and dvdauthor to encode and author; oncemore doctor tells you if something is missing.

macOS (Homebrew)

brew install ffmpeg-full dvdauthor
pip install git+https://github.com/kajisho5/oncemore
oncemore gui my-disc

Debian / Ubuntu

sudo apt-get install ffmpeg dvdauthor genisoimage
pip install git+https://github.com/kajisho5/oncemore
oncemore gui my-disc

oncemore gui opens the app in your browser, served from your own machine. Oncemore.app, the same app in a Mac window for Apple silicon and Intel, will be on the Releases page with the first release; until then the README explains how to build it.
